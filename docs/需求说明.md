# 工作任务清单 —— 功能需求说明

> 本文档为项目初期的需求书，已做脱敏处理：示例姓名统一为「张三」，具体磁盘路径统一记为 `<程序目录>`，涉及具体业务的工作表名称统一为「工作任务清单」。

## 一、总体目标

开发一款 Windows 桌面图形化的「工作任务清单 + 周报总结」工具，最终打包为单文件 exe，放在 `<程序目录>` 中运行。

**兼容性要求：**

- 能在 Windows 7 与 Windows 10 上顺畅运行。
- 早期版本在 Win7 上启动时报 `无法启动程序，缺失 api-ms-win-core-path-l1-1-0.dll`。因此需用 **Python 3.8.10** 构建（3.8 是最后一个原生支持 Windows 7 的版本）。

## 二、界面要求

### ① 时钟头部

展示当日日期、当前时间（数字时钟 + 模拟表盘），以及当前时间距最近一次下班的倒计时。

- 上午时段显示距上午下班的倒计时，下午时段显示距下午下班的倒计时；
- 非上班时间不显示倒计时；
- 精确到分钟，形如「X小时XX分钟」。

作息默认值：

- 夏季：上午 8:30–11:30，下午 14:00–17:30
- 冬季：上午 8:30–11:30，下午 14:30–17:00

两套作息均可在设置界面调整。

### ② 今日工作任务

标题与下方内容左对齐。任务按顺序编号，可增删条目。每条包含：

| 字段 | 交互 |
|---|---|
| 任务序号 | 自动生成 |
| 任务名称 | 点击即可编辑；回车保存当前项并自动新增下一条任务并进入编辑态；点击界面空白处自动保存 |
| 任务时限 | 选填 |
| 是否完成 | 点击切换，完成后任务移入「今日已完成工作任务」 |

**Excel 自动导入：**

- 自动识别程序运行路径下的 `工作任务` 文件夹，打开其中扫描到的首个 Excel 文件（该目录通常只放一个文件）；
- 从「工作任务清单」工作表中读取：D 列为具体任务，O 列为距截止天数；
- 将距截止时间少于 7 天的任务自动加入「今日工作任务」；
- 每次打开软件时自动执行，另设手动刷新按钮；
- 已导入的任务在 30 天内不重复添加（无论是否完成）；
- 设置界面可配置：Excel 文件路径、工作表名称、任务列、时限列。

当日未完成的任务，关闭软件时自动保存，次日打开继续作为当日清单。

### ③ 今日已完成工作任务

展示当天已完成的任务条目。

### ④ 本周工作周报

展示最近一周已完成的任务，按完成日期从旧到新排列并编号，支持手动增删。

- 标题格式：`<署名><起始日期>-<结束日期>工作周报`，例如「张三2026年6月22日-2026年6月26日工作周报」；
- 署名（人名或岗位名）可在设置中自定义；
- 时间范围按当前自然周的周一至周五生成，**不考虑调休与法定节假日**；
- 标题与清单各设一键复制按钮，复制内容仅含标题、序号、任务名称，不含剩余时间、完成时间等附加信息。

### ⑤ 日历

可指定年份与月份，点击某个日期展示当日与当周已完成任务，同样各设一键复制按钮，复制格式与周报一致。

### ⑥ 笔记区

位于界面末尾，可自由编辑并保存，支持一键复制。

## 三、设置与数据

设置界面集中管理上述所有可配置项，设置后持久化生效：

- 作息时间（夏季/冬季）
- Excel 导入参数（路径、工作表、任务列、时限列）
- 周报署名
- 主题配色（内置调色板，可自定义）

**数据备份：** 每次关闭程序时，将清单汇总以 TXT 格式写入 `<程序目录>\清单备份`。设置界面另设手动备份按钮，以及「软件重置」按钮（清除全部参数与数据）。

## 四、图标与外观

使用 `<程序目录>\图标.png` 作为软件图标，要求：

- 程序文件在文件夹中显示该图标；
- 运行时窗口标题栏与任务栏均显示该图标。

程序文字显示清晰度需优化（DPI 适配）。默认主题为初始配色，允许用户通过色盘自定义。

## 五、稳健性

程序需容错：当部分参数缺失或导入表格不存在时，仍能正常启动并降级运行，提示用户前往设置补全，用户亦可选择忽略这些错误。

## 六、交付前自校验

在交付前自行验证：

- 界面可正常滚动与点击；
- 需要显示的元素齐全；
- 数据展示内容及排序符合上述要求。

若校验发现问题，应自行调整修正后再交付。
